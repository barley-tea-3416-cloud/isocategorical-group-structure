# isocategorical-group-structure
Isocategorical Groups of Order 64 and their 2-CocyclesThis repository contains the GAP scripts and computational results for the study of isocategorical but non-isomorphic groups of order 64. The primary focus is on the construction of the twisted group $G^\omega$ using 2-cocycles $\omega \in Z^2(\widehat{N}, \mathbb{T})$ and their structural analysis.
