# isocategorical-group-structure
# Isocategorical Groups of Order 64 and their 2-Cocycles
This repository contains the GAP scripts and computational results for the study of isocategorical but non-isomorphic groups of order 64. 
The primary focus is on the construction of the twisted group $G^\omega$ using 2-cocycles $\omega \in Z^2(\widehat{N}, \mathbb{T})$ and their structural analysis.
# Overview
In this research, we identify groups $G$ of order 64 that admit a normal subgroup $N$ and a $G$-invariant 2-cocycle $\omega$ such that $G^\omega$ is not isomorphic to $G$.
Key features of this project:
- Identification of groups via multiplication tables of generators (since every group of order 64 is generated by at most six elements).
- Classification based on element order lists, which are invariant between isocategorical groups.
- Analysis of 2-cocycles on normal subgroups $N \cong C_2^2, C_4^2,$ and $C_2^4$.
